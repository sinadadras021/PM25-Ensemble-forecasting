PM2.5 ENSEMBLE FORECASTING — SOURCE GUIDE

Start with README.md, then docs/METHODS_ALIGNMENT.md. Configuration is explicit
in configs/paper.json. The default configuration refuses unverified merged
meteorology: establish source clocks and units before a research run.

src/pm25forecast/
  config.py      Scientific defaults, units, time policy and artifact identity.
  data.py        CSV loading, four-condition QC, training-only KNN and scaling.
  windows.py     Station-contained 48h windows and chronological meta split.
  models.py      Figure 2 networks, observed-label MSE and training callbacks.
  ensembles.py   SA, PWE, MLP, XGB, H-MOS and SMS.
  pipeline.py    Prepare, fit, predict, resume checks, ablations and grid search.
  analysis.py    Daily scores, warning metrics, station validation and DM/Holm.
  explain.py     Real Bi-GRU and MLP SHAP using the saved final models.
  plots.py       Three separate publication SHAP figures.
  cli.py         Explicit entry points; no experiment runs merely on import.

tests/ checks the public pipeline using a tiny artificial two-station dataset.
It never opens private station files, downloads data, or reproduces paper scores.
The integration test keeps the actual neural architectures but uses one epoch,
coarse training stride and three-tree ensembles to keep the test small.

No datasets, trained weights, generated figures or paper results are distributed
in this source repository. Earlier commits retain the previous implementation.
